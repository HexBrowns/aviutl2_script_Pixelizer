# モザイク_H

オブジェクトを正方形のブロックに区切り、ブロックごとに 1 色で塗るモザイク（ドット絵風）のアニメーション効果です。
ブロックの格子はオブジェクト基準・画面基準・オブジェクト中心基準から選べ、ブロックの色は中心の 1 点か、ブロック内の平均で決められます。
減色（色数・階調数・パレット）、ディザリング、輪郭の強調も付けられます。

v1.01。nctype さんの `Pixelizer`（v1.0.0・MIT）のフォークです（下の「原作との違い」）。

## インストール

1. `Script\モザイク_H.anm2` を配置する
2. AviUtl2 を再起動する（設定項目の変更は「キャッシュを破棄」では反映されません）
3. オブジェクトに「モザイク_H」を追加する（HexScript の中）

## 使い方

1. モザイクを掛けたいオブジェクト（画像・動画・テキスト・図形）に「モザイク_H」を追加する
2. **ピクセルサイズ** でブロックの大きさ（px）を決める
3. 細い線や小さい文字が消えるときは、**色の決め方** を「ブロックの平均」にする
4. オブジェクトを動かしてもブロックの位置を画面に揃えたいときは、**ドット固定** を「画面固定」にする

初期値のままなら、色は変えずにブロックに区切るだけの素直なモザイクになります（色数・階調数は「無効」、エッジ強度は 0）。

### 例: ドット絵風のテロップ（原作で使っていた設定）

原作の `Pixelizer` を実制作で使っていた設定です。項目名が同じなので、そのまま入れられます。

| 項目 | 値 |
|---|---|
| ドット固定 | 画面固定 |
| ピクセルサイズ | 2 |
| 色数 | 32 |
| 階調数 | 1 |
| エッジ強度 | 0 |
| ほか | 初期値 |

原作は色の量子化を切れなかったので色数を上限の 32 にしていました。モザイク_H では色数を「無効」（0）にすると、
色を丸めずにブロックに区切るだけになります。画面固定なので、長さの違うテロップでもブロックの大きさと位置が揃います。

### 例: レトロゲーム風

| 項目 | 値 |
|---|---|
| パレットモード | GameBoy |
| ピクセルサイズ | 4 〜 8 |
| ディザリング | 2x2 か 4x4 |
| ディザリング強度 | 35（初期値） |

GameBoy の緑 4 色に置き換え、ブロック単位の網点（ディザリング）で中間の明るさを表します。

## パラメータ

### 拡張設定

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| パレットモード | デフォルト / GameBoy / 16-bit / 4階調グレースケール | デフォルト | デフォルトは「色数」で減色する。GameBoy は緑 4 色の近い色、16-bit は R・B を 32 段・G を 64 段、4階調グレースケールは明るさ 4 段の灰色に置き換える。デフォルト以外のときは「色数」で減色しない |
| エッジスタイル | ソフト / エッジ強調 | ソフト | 輪郭の暗くし方。ソフトは輪郭を控えめに暗くする。エッジ強調は輪郭をはっきり黒に近い線にする。エッジ強度が 0 のときは効かない |
| ドット固定 | オブジェクト固定 / 画面固定 / オブジェクト中心 | オブジェクト固定 | ブロックの格子の基準。下の「ドット固定」 |

### ベース

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| ピクセルサイズ | 1 ~ 1000 | 4 | ブロック 1 辺の大きさ（px）。トラックバーで動かせるのはおよそ 1〜100（操作倍率 0.1）で、それより大きい値は数値で入力する |
| 色数 | 0 ~ 256 | 0（無効） | R・G・B をそれぞれ何段に丸めるか。0 と 1 は「無効」で丸めない。パレットモードがデフォルトのときだけ効く |
| 階調数 | 0 ~ 8 | 0（無効） | 明るさを何段に丸めるか（色味は保つ）。0 と 1 は「無効」 |

### ディザリングの設定

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ディザリング | なし / 2x2 / 4x4 | なし | ブロック単位の規則的な網点で、減色した段の間の明るさを表す |
| ディザリング強度 | 0 ~ 100 | 35 | 網点の強さ。ディザリングが「なし」のときは隠れる |

ディザリングは、減色しているとき（**色数が 2 以上**か、**パレットモードがデフォルト以外**）だけ掛かります。
色数が「無効」でパレットモードがデフォルトのときは、ディザリングを選んでも変わりません。

### エッジ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| エッジ強度 | 0 ~ 100 | 0 | 隣のブロックとの明るさ・透明度の差が大きい所（輪郭）を暗くする強さ。0 で輪郭を暗くしない |

### 透過保護（初期状態で閉じています）

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 透明エッジ保護 | ON / OFF | ON | ON なら、不透明度が「透過しきい値」以下のブロックを完全に透明にする。OFF なら半透明のブロックもそのまま残す |
| 透過しきい値 | 0 ~ 255 | 8 | 透明にする不透明度の上限（255 が不透明）。透明エッジ保護が OFF のときは隠れる |

### サンプリング

| 項目 | 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 色の決め方 | 中心の色 / ブロックの平均 | 中心の色 | 中心の色は、ブロックの中心の 1 画素の色で塗る（原作と同じ）。ブロックの平均は、ブロック内の画素の平均の色と不透明度で塗る |

中心の色では、ブロックの中心に掛からない細い線は消えます（1px の線が 16px のブロックで消えることを確かめてあります）。
ブロックの平均なら、線はブロックの中で占める割合の濃さで薄く残ります。

### ドット固定

| 選択肢 | ブロックの格子 |
|---|---|
| オブジェクト固定 | オブジェクトの左上から区切る。ブロックはオブジェクトと一緒に動き、拡大率を上げるとブロックも大きくなる。右端・下端に半端なブロックが出る |
| 画面固定 | 画面の座標で区切る。オブジェクトを動かしてもブロックの位置は画面に固定され、ピクセルサイズは画面上の px になる（拡大率を変えてもブロックの大きさは変わらない）。オブジェクトを Z 軸回転しても、ブロックは画面に対して正方形のまま |
| オブジェクト中心 | オブジェクトの中心を通る線で区切る。左右・上下に対称なモザイクになる |

画面固定が見ているのは、標準描画の X / Y / 拡大率 / 中心 / Z 軸回転と、この効果より前の効果が動かした分だけです。
次の場合は、格子が画面に揃いません。

- この効果より**後ろ**に置いた効果でオブジェクトを動かしたとき（画面に揃えたいなら、動かす効果より後ろにモザイク_H を置く）
- X 軸・Y 軸回転、カメラ制御の下のオブジェクト、グループ制御に追加したとき

## 原作との違い

原作 `Pixelizer` は `oldScript\20260916_モザイク統一\` へ退避してあり、一覧には出ません。

- ピクセルサイズの上限を 64 から 1000 にした
- 色数に「無効」（0）を足した。原作は下限が 2 で、上限の 32 にしても 32 段に丸まった
- 新規に置いたときの初期値を、色を変えない素直なモザイクにした（原作は 色数 8・階調数 4・エッジ強度 20）
- **色の決め方**（ブロックの平均）を足した
- **ドット固定** に「オブジェクト中心」を足した
- 色数が「無効」でパレットモードがデフォルトのときは、1.0 を超える明るさや負の値を 0〜1 に切らずに保つ（階調数を使うとそこで 0〜1 に収まる）
- ディザリングの網点が、オブジェクト中心・画面固定で負の位置のブロックでも崩れないようにした
- ディザリング強度・透過しきい値を、効かないときに隠すようにした

**保存値の互換**: 項目名と選択肢の名前は原作と同じです。同じ値を入れれば、原作と画素単位で同じ絵になります
（原作の初期値にディザリング・エッジ強調を足した設定と、上の実制作の設定で確かめてあります）。
「色の決め方」は原作に無い項目で、初期値の「中心の色」が原作と同じ見え方です。

## 注意

- ブロックの平均で透明エッジ保護が ON のとき、ブロックに対して細すぎる線は、平均の不透明度が透過しきい値を下回って消えます
  （ピクセルサイズ 32 で 1px の線は 1/32 ≒ 8/255 になり、初期値のしきい値 8 で消えます）。消えるときはしきい値を下げるか、透明エッジ保護を OFF にします
- 1080p のオブジェクトに画面固定・ピクセルサイズ 2 を掛けた 1 フレームは、中心の色で 24.1ms、ブロックの平均で 17.7ms でした（30fps の 1 フレーム 33.3ms 以内）。シェーダーを初めて使うフレームだけは、コンパイルの分だけ遅くなります
- オブジェクトの大きさは変えません
