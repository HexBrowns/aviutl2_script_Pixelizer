# モザイク_H

オブジェクトを正方形のブロックに区切り、ブロックごとに 1 色で塗るモザイクのアニメーション効果です。
ブロックの格子はオブジェクト基準・画面基準・オブジェクト中心基準から選べます。
ブロックの色は中心の 1 点・ブロック内の平均のほか、中央値・多数決・最も明るい色・最も暗い色からも選べます。
減色、ディザリング、輪郭の強調も付けられます。

v1.20。nctypeさんの `Pixelizer`（v1.0.0・MIT）をフォークしたものです。

## インストール

1. `Script\モザイク_H.anm2` を配置する。
2. AviUtl2を起動する。
3. オブジェクトに、HexScriptの中の「モザイク_H」を追加する。

## 使い方

1. モザイクを掛けたいオブジェクトに「モザイク_H」を追加する。
2. **ピクセルサイズ** でブロックの大きさを決める。
3. 細い線や小さい文字が消えるときは、**色の決め方** を「ブロックの平均」にする。
4. オブジェクトを動かしてもブロックの位置を画面に揃えたいときは、**ドット固定** を「画面固定」にする。

初期値のままなら、色は変えずにブロックに区切るだけの素直なモザイクになります。

### 例: ドット絵風のテロップ（原作で使っていた設定）

原作の `Pixelizer` を実制作で使っていた設定です。項目名が同じなので、そのまま入れられます。

| 項目 | 値 |
|---|---|
| ドット固定 | 画面固定 |
| ピクセルサイズ | 2 |
| 色数 | 32 |
| 階調数 | 1 |
| エッジ強度 | 0 |
| ほか | 初期値 |

原作は色の量子化を切れなかったので、色数を上限の 32 にしていました。
モザイク_Hでは色数を「無効」にすると、色を丸めずにブロックに区切るだけになります。
画面固定なので、長さの違うテロップでもブロックの大きさと位置が揃います。

### 例: レトロゲーム風

| 項目 | 値 |
|---|---|
| パレットモード | GameBoy |
| ピクセルサイズ | 4 〜 8 |
| ディザリング | 2x2 か 4x4 |
| ディザリング強度 | 35 |

GameBoyの緑 4 色に置き換え、ブロック単位のディザリングで中間の明るさを表します。

## パラメータ

### 拡張設定

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| パレットモード | デフォルト / GameBoy / 16-bit / 4階調グレースケール | デフォルト | デフォルトは「色数」で減色する。GameBoyは緑 4 色の近い色、16-bit はR・Bを 32 段・Gを 64 段、4階調グレースケールは明るさ 4 段の灰色に置き換える。デフォルト以外のときは「色数」で減色しない |
| エッジスタイル | ソフト / エッジ強調 | ソフト | 輪郭の暗くし方。ソフトは輪郭を控えめに暗くする。エッジ強調は輪郭をはっきり黒に近い線にする。エッジ強度が 0 のときは効かない |
| ドット固定 | オブジェクト固定 / 画面固定 / オブジェクト中心 | オブジェクト固定 | ブロックの格子の基準。下の「ドット固定」 |

### ベース

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| ピクセルサイズ | 1 ~ 1000 px | 4 | ブロック 1 辺の大きさ。トラックバーで動かせるのはおよそ 1〜100 で、それより大きい値は数値で入力する |
| 色数 | 0 ~ 256 | 0（無効） | R・G・Bをそれぞれ何段に丸めるか。0 と 1 は「無効」で丸めない。パレットモードがデフォルトのときだけ効く |
| 階調数 | 0 ~ 8 | 0（無効） | 明るさを何段に丸めるか。色味は保つ。0 と 1 は「無効」 |

### ディザリングの設定

| 項目 | 範囲 / 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| ディザリング | なし / 2x2 / 4x4 / 8x8 / ブルーノイズ風 / ホワイトノイズ | なし | ブロック単位の網点で、減色した段の間の明るさを表す。下の表 |
| ディザリング強度 | 0 ~ 100 | 35 | 網点の強さ。ディザリングが「なし」のときは隠れる |

ディザリングは、**色数が 2 以上**か、**パレットモードがデフォルト以外**のときだけ掛かります。
色数が「無効」でパレットモードがデフォルトのときは、ディザリングを選んでも変わりません。

| ディザリング | 網点の見た目 |
|---|---|
| 2x2 / 4x4 | 原作と同じ規則的な網点。2x2 は粗い市松、4x4 は少し細かい格子 |
| 8x8 | 4x4 より網目の細かい格子。段の間の明るさを細かく表せる |
| ブルーノイズ風 | 格子の目立たない、均一なざらつき |
| ホワイトノイズ | ブロックごとにばらばらの、粗い砂目。むらが出やすい。時間では変わらない |

8x8・ブルーノイズ風・ホワイトノイズは v1.20 で足しました。違いは、色数を小さく（2〜4）したときや、GameBoyなどのパレットで広い範囲が中間の明るさになる所でよく見えます。

### エッジ

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| エッジ強度 | 0 ~ 100 | 0 | 隣のブロックとの明るさ・透明度の差が大きい輪郭を暗くする強さ。0 で輪郭を暗くしない |

### 透過保護（初期状態で閉じています）

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 透明エッジ保護 | ON / OFF | ON | ONなら、不透明度が「透過しきい値」以下のブロックを完全に透明にする。OFFなら半透明のブロックもそのまま残す |
| 透過しきい値 | 0 ~ 255 | 8 | 透明にする不透明度の上限。255 が不透明。透明エッジ保護がOFFのときは隠れる |

### サンプリング

| 項目 | 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 色の決め方 | 中心の色 / ブロックの平均 / 中央値 / 多数決 / 最も明るい色 / 最も暗い色 | 中心の色 | ブロックを塗る色の決め方。下の表 |
| リニアで平均 | ON / OFF | OFF | ONなら、平均を光の強さに直してから取る。色の決め方が「ブロックの平均」のときだけ出る |

| 色の決め方 | ブロックを塗る色 |
|---|---|
| 中心の色 | ブロックの中心の 1 画素の色 |
| ブロックの平均 | ブロック内の画素の平均の色と不透明度。縁は混ざった色になる |
| 中央値 | ブロック内で明るさが真ん中の画素の色。ブロックの半分以上が透明寄りなら透明寄りの画素から選ぶので、縁で穴も太りもしない |
| 多数決 | ブロック内でいちばん多い色。似た色はまとめて数える。輪郭がくっきり残る |
| 最も明るい色 | ブロック内でいちばん明るい画素の色。明るい部分が太って見える |
| 最も暗い色 | ブロック内でいちばん暗い画素の色。暗い部分が太って見える。透明な画素は暗い色に数えない |

中央値・多数決・最も明るい色・最も暗い色は v1.20 で足しました。どれもブロックの中に実際にある画素の色で塗るので、平均と違って縁の色がにじみません。
中央値と多数決は、ピクセルサイズが 7 以上のとき、ブロックの中から 6 × 6 の格子の画素だけを読んで決めます。

中心の色では、ブロックの中心に掛からない細い線は消えます。
ブロックの平均なら、線はブロックの中で占める割合の濃さで薄く残ります。

**リニアで平均**は v1.10 で足しました。OFFは v1.01 までと同じ平均です。
OFFの平均は、白黒の細かい模様が実際より暗く沈みます。白と黒の 1px の市松模様をピクセルサイズ 8 で平均すると、OFFで約 128、ONで約 188 の灰色になります。
離れて見たときの明るさに近いのはONです。細かい模様や、明るい点の散った素材をモザイクにするときに使います。

### 色の比較

| 項目 | 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 色差 | RGB / YCbCr / Oklab / CIEDE2000 | RGB | GameBoyの 4 色のうち、どれに置き換えるかを決める色の差。パレットモードが「GameBoy」のときだけ出る |

色差は v1.10 で足しました。RGBは v1.01 までと同じです。

- **RGB**: R・G・Bの差で比べる。今までと同じ
- **Oklab / CIEDE2000**: 見た目の近さで比べる。虹色を置き換えると、緑〜シアンの所が RGB より明るい黄緑になる
- **YCbCr**: 明るさを見ずに色味だけで比べる。GameBoyの 4 色は明るさで分かれているので、ほとんど役に立たない

### ドット固定

| 選択肢 | ブロックの格子 |
|---|---|
| オブジェクト固定 | オブジェクトの左上から区切る。ブロックはオブジェクトと一緒に動き、拡大率を上げるとブロックも大きくなる。右端・下端に半端なブロックが出る |
| 画面固定 | 画面の座標で区切る。オブジェクトを動かしてもブロックの位置は画面に固定され、ピクセルサイズは画面上の px になる。拡大率を変えてもブロックの大きさは変わらない。オブジェクトをZ軸回転しても、ブロックは画面に対して正方形のまま |
| オブジェクト中心 | オブジェクトの中心を通る線で区切る。左右・上下に対称なモザイクになる |

画面固定が見ているのは、標準描画のX / Y / 拡大率 / 中心 / Z軸回転と、この効果より前の効果が動かした分だけです。
次の場合は、格子が画面に揃いません。

- この効果より**後ろ**に置いた効果でオブジェクトを動かしたとき
- X軸・Y軸回転、カメラ制御の下のオブジェクト、グループ制御に追加したとき

画面に揃えたいときは、オブジェクトを動かす効果より後ろにモザイク_Hを置きます。

## 原作との違い

- ピクセルサイズの上限を 64 から 1000 にした
- 色数に「無効」を足した。原作は下限が 2 で、上限の 32 にしても 32 段に丸まった
- 新規に置いたときの初期値を、色を変えない素直なモザイクにした。原作は 色数 8・階調数 4・エッジ強度 20
- **色の決め方** を足し、ブロックの平均で塗れるようにした
- **ドット固定** に「オブジェクト中心」を足した
- 色数が「無効」でパレットモードがデフォルトのときは、1.0 を超える明るさや負の値を 0〜1 に切らずに保つ。階調数を使うとそこで 0〜1 に収まる
- ディザリングの網点が、オブジェクト中心・画面固定で負の位置のブロックでも崩れないようにした
- ディザリング強度・透過しきい値を、効かないときに隠すようにした
- **リニアで平均** と、GameBoyの **色差** を足した
- ディザリングに 8x8・ブルーノイズ風・ホワイトノイズを、色の決め方に 中央値・多数決・最も明るい色・最も暗い色 を足した

**保存値の互換**: 項目名と選択肢の名称は原作と同じです。
同じ値を入れれば、原作と画素単位で同じ絵になります。
「色の決め方」「リニアで平均」「色差」は原作に無い項目で、初期値が原作と同じ見え方です。

## 注意

- ブロックの平均で透明エッジ保護がONのとき、ブロックに対して細すぎる線は、平均の不透明度が透過しきい値を下回って消えます。
  ピクセルサイズ 32 の 1px の線は、初期値のしきい値 8 で消えます。消えるときはしきい値を下げるか、透明エッジ保護をOFFにします
- 1080p のオブジェクトに画面固定・ピクセルサイズ 2 を掛けた 1 フレームは、中心の色で 24.1ms、ブロックの平均で 17.7ms でした。シェーダーを初めて使うフレームだけは、コンパイルの分だけ遅くなります
- オブジェクトの大きさは変えません
- v1.10 で設定項目を、v1.20 で選択肢を足しました。ファイルを入れ替えたときは、AviUtl2の再起動が必要です
- v1.20 では選択肢を末尾に足しただけで、初期値（ディザリング なし・色の決め方 中心の色）は v1.10 と同じ見た目です。保存済みのプロジェクトはそのまま開けます
